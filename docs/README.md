## Règles

- Un bilan par version, une page : fait, vérifié comment, pas fait. Le bilan précédent part
  dans `archive/`.
- Pas de « conseil de personas » simulé, pas de rapport en double.
- Les captures et les rapports des recettes vont dans `artifacts/`, jamais dans Git.
