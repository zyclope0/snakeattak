# Emporter l’aventure — version 0.20

Dans le menu principal, ouvrir **Sauvegarde familiale**, puis **Exporter**.
Conserver le fichier JSON téléchargé sur son appareil ou le transférer soi-même.
Sur l’autre appareil, ouvrir le même menu, choisir le fichier, lire son aperçu
puis confirmer le remplacement. Annuler conserve l’aventure en cours.

Le fichier contient le dernier camp préparé, les meilleures étoiles et les trois
équipes favorites. Une bataille commencée se rejoue depuis son début. Après la
victoire finale, les étoiles sont conservées avec le dernier camp préparé.
Ce transfert est manuel : les appareils ne se synchronisent pas automatiquement.

Le site reste à la même adresse :
https://conquete-serpents-famille.zyclope.chatgpt.site
L’accès privé utilise le compte ChatGPT propriétaire. Une mise à jour à cette même
adresse conserve normalement le stockage du navigateur si celui-ci est autorisé.

Pour reprendre depuis un ancien ZIP, conserver une copie de l’ancien JOUER.html,
puis remplacer JOUER.html au même emplacement par celui de cette version. Si le
navigateur retrouve l’ancien camp, l’exporter depuis Sauvegarde familiale et
l’importer sur le site. Le stockage des fichiers locaux dépend du navigateur et
du chemin : ne pas déplacer ou effacer l’ancien fichier avant d’avoir exporté.
Si le camp n’est plus présent, cette version ne peut pas récupérer des données
que le navigateur a déjà supprimées. Privilégier le site HTTPS pour jouer.

Un fichier invalide ou un stockage refusé affiche un message ; l’import n’annonce
pas de réussite et ne remplace pas la session en cours. Les exports n’incluent pas
de nom de joueur ni de secret. Aucun compte de jeu supplémentaire n’est nécessaire.
