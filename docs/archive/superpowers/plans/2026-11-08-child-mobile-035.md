# Child mobile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** rendre recrutement et miel directement accessibles sur téléphone, avec textes cohérents.

**Architecture:** gestes transitoires dans Session ; dock HTML/CSS et helpers UI purs ; commandes Game existantes, rendu observateur.

**Tech Stack:** TypeScript, Phaser 3, Vite, Capacitor 8.6, Node 24, Playwright.

**Spec:** ../specs/2026-11-08-child-mobile-design.md

## Global Constraints

- Aucun changement de Game, données d'équilibrage, RNG ou formats de sauvegarde.
- Quatre raccourcis selon favoris déverrouillés ; catalogue complet conservé.
- Miel gratuit une fois par vague, limites et durée contrôlées par Game.
- Pas d'ordre manuel, nouveau SDK, frais ou génération d'image.
- Version 0.31.0, Android code 34 ; tester les tailles et marges de la spec.

## Review Focus

- Favoris verrouillés ou trop chers : stabilité des quatre raccourcis, aucune perte de préférences.
- Sélection allié/miel, récompense offerte et changement de Game : aucune commande ambiguë.
- Toucher entre les chemins ou une voie paisible : aucun miel consommé.
- Pause/interruption/dialogue : aucune action derrière une pause, aucune reprise automatique.
- Petit paysage avec barres système : dock/catalogue utilisables, pas de voie masquée.
