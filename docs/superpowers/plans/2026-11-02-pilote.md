# Pilote — Implementation Plan

> Exécution autonome autorisée par l'utilisateur. Implémentation dans cette session.

**Goal:** une partie courte jouable de La Conquête des Serpents.
**Architecture:** simulation TypeScript déterministe, A* partagé, scène Phaser, interface HTML tactile.
**Tech Stack:** Phaser 3, TypeScript, Vite, tests natifs Node.
**Spec:** GAME_DESIGN.md et accord de l'utilisateur dans la discussion.

## Contraintes

Prototype V4 préservé ; deux zones ; unités autonomes sans déplacement manuel ; morts définitives ; aucune API nécessaire en jeu. Six vagues pour ce pilote, boss à la dernière. Équilibrage proposé, à jouer avec l'enfant.

## Audit V4

Fonctionnel à la lecture : recrutement tactile, 13 types, soins, vagues, récompenses, A*, pause, vitesse, victoire et défaite.
Limites : héros initial absent ; emojis comme personnages ; pathfinding recalculé aléatoirement et retour au déplacement direct si aucun chemin ; ennemis sans navigation ; pas de sauvegarde ; œufs seulement décoratifs. La maquette contient des commandes manuelles contraires aux règles : elles ne sont pas reprises.

## Tâches

- [x] Simulation : catalogue, navigation A*, économie, vagues, combat et soins. Tester recrutement invalide, mort définitive, pause, victoire/défaite, chemins bloqués et répétabilité.
- [x] Scène : terrain dessiné, serpent Magnific, soldats dessinés, HUD responsive, achat, pause, vitesse, recommencer, aide et lien V4.
- [x] Livraison : tests de simulation, build, essai navigateur si possible, archive source et distribution. Documenter les limites.

## Review focus

Mobile étroit ; pause pendant recrutement ; chemin inaccessible ; dégâts de base sans récompense d'élimination ; réinitialisation après fin.

## Décisions

Six vagues, trois renforts achetables et palissade pour un pilote court. Héros initial autonome. Œufs et catalogue étendu différés. Aucune génération payante supplémentaire nécessaire pour cette version. Pas de publication externe implicite.

## Résultat

Simulation et navigateur validés. Relecture indépendante terminée ; trois défauts corrigés et couverts par régressions. Livraison HTML autonome choisie pour contourner le problème de récupération du projet cloud. Décision de pilote : le boss entré dans le camp entraîne la défaite, même si la base avait encore de la vie.
